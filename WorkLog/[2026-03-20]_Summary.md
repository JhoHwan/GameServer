# 2026-03-20 작업 요약

## 1. 게임 오브젝트 생성의 필드 종속성 확보
- **관리 주체 이전:** 기존 `GameManager`가 전역적으로 플레이어를 생성하던 방식을 폐기하고, 모든 `GameObject`의 생성(`Spawn`) 및 소멸(`Despawn`) 권한을 `Field` 클래스 내부로 제한했습니다.
- **좀비 객체 차단:** 객체가 생성됨과 동시에 해당 필드의 `_objects` 맵에 등록되도록 강제하여, "필드 없는 객체"가 허공에 생성되거나 메모리에 잔존하는 문제를 원천적으로 차단했습니다.
- **Factory Pattern & AccessKey:** (옵션) 객체 생성 인터페이스를 보호하여, 필드 외의 시스템에서 임의로 객체를 생성할 수 없도록 아키텍처를 견고하게 만들었습니다.

## 2. 로딩 지연 스폰 및 부하 분산 아키텍처 구축
- **지연 생성 (Lazy Spawning):** 플레이어가 접속(`CS_REQ_ENTER_GAME`)할 때 객체를 즉시 만들지 않고, `GameSession`에 목적지 맵 ID와 스폰 좌표만 임시로 저장합니다.
- **메모리 최적화:** 클라이언트가 실제 맵 로딩을 완료하고 `CS_FIELD_LOADING_COMPLETE` 패킷을 보낸 직후에 비로소 필드에서 객체를 `new`하여 메모리 낭비를 줄였습니다.
- **JobQueue 분산 처리:** `GameManager`에 집중되던 접속, 스폰, 이동 로직을 각 `Field`의 `JobQueue`로 완벽히 분산시켜, 대규모 동시 접속 시 발생할 수 있는 병목(Bottleneck) 현상을 해결했습니다.

## 3. 스레드 세이프(Thread-Safe) 동기화 및 라이프사이클 분리
- **Field 단일 큐 공유:** `PlayerCharacter`가 독자적인 비동기 스레드(`AsyncActor`)를 돌리던 구조를 개편하여, 모든 이동(`SetMoveInfo`)과 상태 변화가 자신이 속한 필드의 큐 안에서 실행되도록 수정했습니다. 이로써 객체 간 상호작용 시 Lock이 필요 없는 완벽한 동기화를 이루었습니다.
- **책임 분리 (SRP):** `Field` 클래스는 명단 추가/삭제(`_players.insert/erase`)만 담당하고, 특정 타입의 스폰/디스폰 시 발생하는 패킷 전송 및 브로드캐스팅 로직은 `GameObject::OnSpawn` / `OnDespawn` 가상 함수로 이관하여 확장성을 극대화했습니다.

## 4. 예외 상황 및 이동 간 상태 꼬임 버그 수정
- **소멸자 의존성 제거:** 맵 이동 시 `Player A`가 소멸하면서 `Player B`의 세션 연결까지 끊어버리던 타이밍 버그를 해결하기 위해, 세션 초기화 로직을 소멸자에서 `OnDespawn`으로 이동시켰습니다.
- **강제 종료 방어:** 클라이언트가 로딩 중 혹은 비정상적으로 연결을 끊었을 때(`OnDisconnected`), 기존의 불안전한 `LeavePlayer` 호출 대신 `Field::Despawn`을 명시적으로 호출하여 메모리 릭과 브로드캐스팅 누락을 방지했습니다.

// Server/GameServer/Contents/Field/Field.h : 필드 종속적 스폰 구조
// - 외부에서 객체만 생성하고, 필드 JobQueue 내부에서 등록 및 활성화를 보장함
template<GameObjectType T, typename ... Args>
void Field::Spawn(const Vector3& spawnPos, Args&&... args) {
    shared_ptr<T> newObject = GameObject::Create<T>(std::forward<Args>(args)...);
    newObject->SetField(shared_from_this());
    newObject->Transform()->SetPos(spawnPos); // OnSpawn 전 좌표 세팅 필수

    DoAsync([fieldRef = weak_from_this(), newObject = std::move(newObject)]() {
        auto self = fieldRef.lock();
        if (!self) return;
        self->_objects.emplace(newObject->GetId(), newObject);
        newObject->OnSpawn(); // 객체 스스로 패킷 전송
    });
}

void PlayerCharacter::OnDespawn() {

    if(auto session = GetSession()) session->SetPlayer(nullptr); // 소멸자 대신 여기서 세션 연결 해제
