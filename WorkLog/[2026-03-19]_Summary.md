# 2026-03-19 작업 요약

## 1. 서버 주도 시간 동기화(NTP) 시스템 구축
- **3-Way Handshake 도입:** 서버가 `SC_PING`을 보내고 클라이언트가 `CS_PONG`으로 응답하면, 서버가 최종 RTT와 오프셋을 계산해 `SC_TIME_SYNC`로 내려주는 정석적인 NTP 알고리즘을 구현했습니다.
- **초기 고속 동기화 및 EMA 스무딩:** 연결 직후에는 5회의 핑을 고속(100ms 주기) 전송하여 초기 오차를 빠르게 제거하고, 이후에는 지수 이동 평균(EMA)을 적용해 네트워크 상황에 따라 오프셋을 부드럽게 상시 보정하도록 했습니다.
- **자체 시간 관리자(`Time::GetServerTime`) 도입:** 서버 구동 시점을 기준으로 하는 `uint64` 기반 틱 함수를 구현하여 OS 부팅 시간 의존성을 제거하고 안정성을 확보했습니다.

## 2. 이동 패킷 타임스탬프 기반 정합성 고도화
- **클라이언트 클릭 시점 동기화:** `CS_REQUEST_MOVE` 패킷에 클라이언트 로컬 타임스탬프를 포함했습니다. 서버는 저장된 오프셋을 더해 클라이언트가 실제 클릭한 "과거의 서버 시간"을 도출하고, 그 시점부터 보간을 시작하여 이동 오차를 최소화했습니다.
- **하트비트 검사 로직 통합:** 기존 `SetTimeOut` 방식이 다른 상태 타임아웃과 충돌하던 문제를 해결하기 위해, 핑 타이머 루프 내에서 마지막 퐁 수신 시간을 직접 체크하는 독자적인 하트비트 감시 구조로 개편했습니다.

## 3. 필드 중도 진입 시 프록시 캐릭터 이동 끊김 해결
- **타임라인 원형 복원 전송:** 새로 입장한 유저에게 주변 이동 중인 플레이어 정보를 보낼 때, 현재 시간으로 재계산하던 방식을 버리고 원본 시작 시간과 전체 경로 데이터를 그대로 복사해서 보내도록 수정했습니다.
- **클라이언트 즉시 합류:** 이를 통해 늦게 들어온 클라이언트도 프록시 캐릭터의 이동 궤적 중간 지점에 즉시 보간을 맞춰 합류하게 되어, 순간이동이나 멈춤 현상을 해결했습니다.

## 4. 클라이언트 시간 계산 로직 교정 및 입장 순서 제어
- **오프셋 중복 합산 버그 수정:** 클라이언트가 누적 도착 시간(Cumulative Offset)을 한 번 더 누적하여 속도가 느려지던 문제를 교정하고 로컬/서버 간 시간 규격을 통일했습니다.
- **입장 순서 안정화:** 시간 동기화(Offset 산출)가 1회 이상 완료된 시점에만 `CS_ENTER_GAME`을 보내도록 클라이언트 로직을 조정하여, 초기 위치 정보가 꼬이는 현상을 방지했습니다.

// Server/GameServer/GameSession.cpp: NTP 오프셋 계산 및 스무딩
// - 서버 기준의 절대 시간 T4를 구하고 NTP 공식을 통해 오프셋 산출
// - 초기 5회는 평균을 내고 이후엔 EMA 보정을 통해 튀는 값을 제어함
void GameSession::HandlePong(const uint64& T1, const uint64& T2, const uint64& T3) {
    uint64 T4 = Time::GetServerTime();
    _lastPongTime.store(T4); 

    uint64 rtt = (T4 - T1) - (T3 - T2);
    int64 currentOffset = static_cast<int64>(T4) - static_cast<int64>(T3 + (rtt / 2));

    if (_syncPingsReceived.load() < INITIAL_PING_COUNT) {
        _accumulatedOffset.fetch_add(currentOffset);
        if (_syncPingsReceived.fetch_add(1) + 1 == INITIAL_PING_COUNT) {
            _serverOffset.store(_accumulatedOffset.load() / INITIAL_PING_COUNT);
        }
    } else {
        int64 prevOffset = _serverOffset.load();
        _serverOffset.store(static_cast<int64>((prevOffset * 0.9f) + (currentOffset * 0.1f)));
    }
}

// Server/GameServer/Contents/Field/Field.cpp: 프록시 캐릭터 이동 정보 전송
// - 현재 시간을 기준으로 경로를 깎지 않고 원본 경로와 시작 시간을 온전히 전송
// - 클라이언트가 서버 오프셋을 적용해 정확한 중간 지점부터 보간하게 유도
if(other->IsMoving()) {
    Protocol::SC_MOVE_PATH movePacket;
    movePacket.set_start_server_tick(other->GetMoveStartTime()); 
    const auto& waypoints = other->GetWaypoints();
    const auto& arrivalTimes = other->GetArrivalTimes();

    for (size_t i = 0; i < waypoints.size(); ++i) {
        auto* wp = movePacket.add_waypoints();
        wp->mutable_pos()->CopyFrom(waypoints[i].ToProto());
        wp->set_arrival_offset_ms(static_cast<uint32>(arrivalTimes[i] - other->GetMoveStartTime()));
    }
}

// - 클라이언트 로컬 틱에 계산된 서버 오프셋을 더해 정확한 서버 시작 틱 산출
// - 보정된 틱을 바탕으로 서버 길찾기 시뮬레이션을 시작함
uint64 transformedServerTick = pkt.client_tick() + gSession->GetServerOffset();
