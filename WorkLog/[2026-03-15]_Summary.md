# 2026-03-16 작업 요약

## 1. 멀티 플랫폼 네트워크 엔진 (ServerCore) 추상화 및 고도화
- **이중 I/O 모델 구현:** Windows의 IOCP(Proactor)와 Linux의 Epoll(Reactor)을 공통 인터페이스(`NetCore`)로 완벽히 추상화했습니다.
- **Linux 안정성 확보:** `epoll_event.data.u64`를 활용한 Ticket 시스템(FD + Generation)을 도입하여, 멀티스레드 환경에서 소켓 재사용 시 발생할 수 있는 레이스 컨디션과 댕글링 포인터 문제를 근본적으로 해결했습니다.
- **송신 최적화:** Linux 환경에서 `sendmsg`를 이용한 Vectorized I/O(`FlushSend`)를 구현하여 대량의 패킷 전송 시 시스템 콜 오버헤드를 최소화했습니다.

## 2. NavMesh 기반 정밀 물리 검증 및 이동 시스템
- **서버 사이드 보간 (Server-side Interpolation):** 클라이언트가 전송한 경로를 바탕으로 서버 내에서 `_moveArrivalTimes`를 산출, 현재 틱 기준의 정밀한 위치를 실시간으로 계산하는 `GetCurrentPosition` 로직을 확립했습니다.
- **Raycast Fast-path 도입:** 경로 탐색(`FindPath`) 시 Detour의 `raycast`를 우선 수행하여 장애물이 없는 직선 구간은 복잡한 A* 연산 없이 즉시 반환하도록 최적화했습니다 (실행 시간 약 4~6us).
- **이동 빈도 제한 (Throttling):** 500ms의 최소 간격과 300cm의 최소 거리 조건을 적용하여 무분별한 이동 요청 패킷으로 인한 서버 부하를 방지했습니다.

## 3. 필드 인스턴스 자동 확장 및 생명주기 관리
- **부하 분산 기반 입장:** `FieldManager`가 맵별 인스턴스 수용 인원을 체크하여 자동으로 확정하고, 모든 인스턴스가 꽉 찼을 경우에만 새 필드를 생성하도록 구현했습니다.
